# DSCI 552 Homework 3

This repository contains Homework 3 for DSCI 552.

## Repository Structure

- `data/AReM/`: Activity Recognition dataset containing seven activity folders (bending1, bending2, cycling, lying, sitting, standing, and walking)
- `notebook/`: Jupyter Notebook submission
- `requirements.txt`: Python dependencies

The notebook uses relative paths so it can be executed without machine-specific absolute paths.
